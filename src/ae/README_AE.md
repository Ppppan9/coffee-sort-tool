# 咖啡分拣 · After Effects 工程导出说明

## 使用步骤
1. 网页工具中点「▶ 自动通关」（自动开始记录），或在面板「导出 AE 工程」里点「● 开始记录」后手动游玩；完成后点「■ 停止并导出」/「⬇ 导出 ZIP」，得到 `coffee_ae_export_*.zip`。开启「录制视频时同步记录，停止录制后自动导出」时，停止视频录制会自动导出。
2. 解压到任意文件夹（保持 `build_ae_project.jsx`、`timeline.json`、`assets/`、`audio/` 在同一目录）。
3. After Effects（CC 2018 及以上）→ 文件 → 脚本 → 运行脚本文件… 选择 `build_ae_project.jsx`。脚本按自身位置查找素材，不需要改路径。
4. 脚本新建工程、导入素材、建立「主合成_咖啡分拣」（尺寸=「AE 合成尺寸」，帧率=「AE 合成帧率」），完成后会弹出统计（图层数 / 关键帧数 / 标记数），并询问是否**另存为 .aep**（「脚本跑完后提示另存为 .aep」）。

> 如果提示“脚本没有写入文件的权限”：在 编辑 > 首选项 > 脚本和表达式 勾选 **允许脚本写入文件和访问网络**。只影响最后一步保存 .aep。

## 文件
| 路径 | 内容 |

## 图层结构（从下到上）
- 背景（沙地）、传送带、棋盘（托盘框 + 蓝色底板）
- 咖啡杯_N：传送带上的每个杯子一层（位置/缩放关键帧沿蛇形传送带前进），离开传送带后飞入托盘凹槽、跟随纸箱合盖时出点
- 托盘_NN：每个托盘一层（位置/缩放关键帧：透视缩放 + 按下 + 被挡抖动 + 滑向出口）；托盘_NN_红光：被挡时的红色闪光（不透明度关键帧）
- 纸箱_N 张开 / 纸箱_N 合盖：出现（缩放）、合盖、沿弧线飞向计数器并淡出
- 计数器_999 …：每个数值一层（入/出点即数值变化时刻）
- Nice_ / 闪光_：完成提示弹出（缩放回弹 + 淡出）
- 免责声明（若开启）、结束页（若开启，不透明度关键帧）
- 手指：内置“手 + 白色触控笔”或上传的 PNG，锚点 = 笔尖，位置 + 按下缩放
- 混合音轨 / 音效_逐事件（预合成，每个音效一层放在发生时刻），主合成每个音效事件一个标记（按下 / 滑动 / 落杯 / 纸箱合盖 / Nice提示 / 错误）。

## 3D 外观图层（v1.2，设置「AE 图层外观」：跟随页面 / 3D / 2D）
记录时页面开启了「3D 渲染」时默认导出 3D 外观（「跟随页面」），用页面同一个 three.js 场景离屏渲染素材：
- 传送带、棋盘：各一张整帧 3D 渲染图（`belt3d.png` / `board3d.png`）。
- 托盘_NN：每块托盘一张 3D 精灵（`tile3d_NN_<色>_<宽>.png`，在它开局的格子位置渲染，透视与该格一致）；移动 / 按下 / 抖动仍是逐帧位置 / 缩放关键帧（缩放按渲染时的参考缩放换算）。
- 咖啡杯_N：每色 × 4 个纵向分带一张 3D 精灵（`cup3d_<色>_b<带>.png`），杯子跨带时自动拆成多段图层，每段用该带的精灵。
- 纸箱_N 3D序列：纸箱长出 + 翻盖合上（含箱内托盘与杯子）逐帧 3D 渲染 → 预合成「纸箱3D序列_<色>_<宽>_n<帧数>」（每帧一个单帧图层，同色同宽的纸箱复用同一预合成）；纸箱_N 合盖：飞走阶段用合好的最后一帧作静帧 + 位置 / 缩放关键帧。
- 计数器、Nice、闪光、星星、免责声明、结束页、手指仍为 2D 图层（与页面 3D 模式下的 2D 覆盖层一致）。
为什么不是“每个元素每帧一张 PNG”：几百个元素 × 上千帧会让 zip 达到数百 MB；上面的方案只对真正有 3D 形变的纸箱用逐帧序列，其余用按角度 / 位置渲染的精灵，zip 只增加几 MB。
近似：托盘 / 杯子移动到别处时沿用原位置渲染的精灵（透视角度不随位置变化），元素之间的相互遮挡 / 投影按图层顺序叠加。选「2D 精灵」可导出 v1.1 的纯 2D 图层。

## 说明
- 图层命名可选中文/English（「图层命名」），与麻将工具同一规范（见 ref/TOOLKIT_STANDARD.md）。
- 网页画面本身就是由同一组精灵（素材 + 位置/缩放/旋转/不透明度）绘制的，导出的 AE 合成与网页逐像素一致（`npm run test:ae` 校验 PSNR）。
- 关键帧默认「精简」（线性插值误差 ≤0.25px 内删减），可改为「逐帧烘焙」。
- 若在记录后修改了画布/外观参数，请重新开始一局再导出。
